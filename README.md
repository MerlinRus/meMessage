# meMessage / iPhone Bridge

Нативное приложение Windows на Rust для сообщений через сопряжённый iPhone.
Интерфейс в стиле macOS Messages: SF Pro во всех текстовых стилях, SVG-иконки,
цветные Apple emoji в сообщениях и панели выбора, диалоги и поиск.
Без Mac, Electron, WebView, Apple ID и облачного сервера.

## Запуск

Запусти `iMessage.exe` в корне проекта или `Start-Bridge.cmd`. Рядом нужна папка
`assets`. iPhone должен быть сопряжён с Windows по Bluetooth и находиться рядом.

На iPhone: **Настройки → Bluetooth → ⓘ рядом с ноутбуком → Показывать уведомления**.
Для имён включи **Синхронизация контактов**, при наличии — **Все контакты**.

- **Enter** отправляет текст; **Shift+Enter** добавляет строку.
- **Ctrl+N** — новое сообщение, **Ctrl+F** — поиск по имени, номеру и сообщениям.
- Панель emoji позволяет выбрать несколько подряд; Escape или клик снаружи закрывает её.
- Нажми собеседника в заголовке → **Имя контакта → Сохранить имя**, чтобы подписать
  номер на ноутбуке. Контакт на телефоне не изменяется.
- Там же можно **Добавить фото**, **Изменить фото** или **Убрать фото** контакта.
  Поддерживаются JPEG, PNG и WebP до 16 МБ; изображение обрезается по центру.
  Фото хранится зашифрованным на компьютере и не меняется при обновлении имён.
- Там же есть **Обновить контакты с iPhone**. При запуске телефонная книга
  запрашивается через PBAP; ручное имя имеет приоритет.
- Уведомления Windows работают, пока приложение открыто или свёрнуто.
  Клик открывает диалог. Новые сообщения проверяются в фоне каждые 3 секунды.
- При отсутствии связи внизу боковой панели есть **Подключить**: проверка
  запускается сразу, во время попытки кнопка недоступна. iPhone должен быть
  уже сопряжён с Windows по Bluetooth.
- Открытый активный чат отмечается прочитанным. Его синий индикатор не
  возвращается после обновления; прочтение хранится в локальной истории.
- После отправки сразу можно писать следующий текст, в том числе пока iPhone отвечает.
- Возврат в приложение возвращает фокус в поле ввода (отключается в настройках).
- **Кнопка настроек / Ctrl+,** — настройки: анимации, автофокус, уведомления и звук, период
  обновления, сохранение истории и черновиков, сворачивание при закрытии.
- Черновики восстанавливаются после перезапуска. В настройках есть ссылка
  **Сделано by MAARK** на [maark.ru](https://maark.ru) с анимацией при наведении.

Имена и история хранятся локально, зашифрованными Windows DPAPI для текущего
пользователя в `%LOCALAPPDATA%\meMessage` (история, контакты, настройки и черновики).
Старая папка `data/` переносится копированием без удаления или перезаписи файлов.
Для переносного режима создай `portable.flag` рядом с exe: данные будут в `data/`. Эти данные,
диагностика и локальные сборки исключены из Git.

## Возможности iPhone

iPhone выбирает iMessage или SMS. Синий пузырь — оформление, а **Передано iPhone**
подтверждает приём телефоном, но не доставку адресату. При потере ответа отправка
не повторяется автоматически: сначала проверь переписку на телефоне.

Фотографии в текущем Bluetooth-канале недоступны. Проверка реального iPhone с
`Attachment=1` возвращает тот же текст `Attachment: 1 Image`, что и с `Attachment=0`,
без файла изображения. Вместо английской заглушки показывается объяснение.
Вставка картинки через Ctrl+V сообщает об ограничении и сохраняет введённый текст.
**Отправка фотографий не реализована** — для неё потребуется другой канал к iPhone.
См. [ответ инженера Apple](https://developer.apple.com/forums/thread/772378).

Полная история исходящих с телефона, групповые ответы, звонки и подтверждения
доставки также недоступны в этой реализации. Новые ответы приложения сохраняются.
История, которую приложение уже получило, сохраняется без прежнего лимита в 2000
сообщений. При подключении загружаются доступные страницы; реальный iPhone в
проверке открыл 10 входящих и пустые следующие страницы. Полный пропущенный архив
и исходящие, отправленные с телефона, этим не восстанавливаются.

Поведение и сглаживание macOS не воспроизводятся пиксель в пиксель на Windows.

## Сборка

Нужны Rust stable `x86_64-pc-windows-msvc` и MSVC Build Tools с Windows SDK.

```powershell
git clone https://github.com/MerlinRus/meMessage.git
cd meMessage
pwsh -File .\Setup-Assets.ps1
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --check
pwsh -File .\Build.ps1
```

`Setup-Assets.ps1` загружает зафиксированные версии SF Pro и emoji-атласа с
проверкой SHA-256. Они используются локально и не включаются в публичный репозиторий.
Источники и права — в [THIRD_PARTY.md](THIRD_PARTY.md).

`build.rs` встраивает многоразмерную иконку в exe. Приложение имеет постоянный
AppUserModelID, ярлык с явной иконкой и исправляет свои закреплённые ярлыки.

## Диагностика

```powershell
.\iMessage.exe --preview --compact
.\iMessage.exe --preview
.\iMessage.exe --probe
.\iMessage.exe --probe-contacts
.\iMessage.exe --probe-history
.\iMessage.exe --probe-capabilities
.\iMessage.exe --probe-attachments
.\iMessage.exe --notify-test
.\iMessage.exe --repair-shortcuts
```

Предпросмотр использует тестовые диалоги без iPhone, отправка отключена.
`--probe*` выполняют чтение и сохраняют технические счётчики в `%LOCALAPPDATA%\meMessage\diagnostics` (в переносном режиме — `data/diagnostics`), без имён,
номеров и текстов переписки. `--notify-test` показывает локальное уведомление
и ждёт нажатие до 30 секунд.

Тесты проверяют настоящий egui-интерфейс через дерево доступности и события
мыши/клавиатуры. Протокол проверяется подставным транспортом; тесты не отправляют
реальных сообщений. Сценарии и пределы проверки — в [QA.md](QA.md).

## Исходники

`ui.rs` — интерфейс, `composer.rs` / `layout.rs` — поле ввода и геометрия,
`motion.rs` — анимации, `contacts.rs` — PBAP и локальные имена,
`notifications.rs` — уведомления и ярлыки, `map.rs` / `transport.rs` — Bluetooth,
`settings.rs` — настройки и черновики, `platform.rs` — нативное окно,
`capabilities.rs` — чтение SDP-возможностей, `icons.rs` — встроенные SVG, `avatars.rs` — обработка локальных фото контактов,
`model.rs` — история, `worker.rs` — фоновые операции, `media.rs` — вложения.

## Статус публичного выпуска

Это рабочая экспериментальная версия, не полный клиент iMessage. Фото, полный
архив и ручной выбор iMessage/SMS остаются открытыми задачами. Для полностью
беспроводного режима без помощника на телефоне подходящий канал пока не найден.
Wi-Fi-объявление само по себе не означает доверие компьютеру; существующие записи
Apple в проверке не подошли. См. [описание протоколов pymobiledevice3](https://github.com/doronz88/pymobiledevice3/blob/master/misc/understanding_idevice_protocol_layers.md).

Перед массовым выпуском также нужны подпись сборок и установщик, проверка на
других Windows/iPhone и отдельная проверка прав на распространяемые графические
ресурсы. Apple-шрифты и emoji в публичный репозиторий не включены. Автотесты
GitHub Actions отключены по решению владельца; локальные тесты сохранены.
